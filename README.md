# Бизнес-панель ПСД

Панель управления проектно-сметным бюро в трёх рабочих зонах:

- **Сметы**: сметы, проектная документация, замечания экспертизы.
- **ИТД**: исполнительная документация по Приказу Минстроя 344/пр, журналы работ (1026/пр), сертификаты и паспорта.
- **Бизнес**: договоры, счета, акты, банк, закупки, заказчики, исполнители, интеграции.

Объекты, задачи, глобальный поиск и AI-помощник общие для всех зон.

> Все цифры, организации и ИНН в панели примерные. Это макет для обсуждения и настройки под реальные процессы.

## Состав репозитория

| Файл | Что это |
|---|---|
| `index.html` | Вся панель в одном файле: вёрстка, стили, данные и логика |
| `README.md` | Эта инструкция |

Сборка, сервер и база данных не нужны.

## Три способа запуска

### 1. На claude.ai: полная версия (рекомендуется)

Панель опубликована как артефакт Claude, ссылка «Бизнес-панель ПСД» есть в разделе артефактов claude.ai. Только в этом режиме работает всё:

- **AI-помощник** отвечает по данным панели и пишет письма;
- **AI-поиск поставщиков** даёт ориентировочные цены и сроки;
- **общая база записей**: созданные акты, заявки, счета и объекты видны всем, с кем вы поделились панелью.

Чтобы дать доступ сотрудникам, откройте артефакт и нажмите «Поделиться».

Если панель нужно опубликовать заново, например после правок в `index.html`, попросите Claude: «опубликуй index.html из репозитория как артефакт с возможностями db и sample».

### 2. На своём компьютере: без установки

1. Скачайте репозиторий: на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте `index.html` двойным щелчком. Подойдёт Chrome, Edge, Safari или Firefox.

Работает всё, кроме AI. Созданные записи хранятся только в этом браузере на этом компьютере: в шапке будет надпись «В этом браузере». Для значков нужен интернет, они загружаются с unpkg.com.

### 3. На внутреннем сервере или хостинге

Положите `index.html` в любую папку веб-сервера (nginx, Apache, IIS) или на статический хостинг. Настраивать ничего не нужно. Возможности будут как в способе 2.

Быстрая проверка через Python:

```bash
cd biznes-panel-psd
python3 -m http.server 8080
# откройте http://localhost:8080
```

> GitHub Pages для закрытого репозитория доступен только на платных тарифах GitHub (Pro, Team, Enterprise).

## Что умеет панель

- **Переключатель зон** в шапке: «Сметы / ИТД / Бизнес». Панель запоминает последнюю открытую зону.
- **Кнопка «Создать»** открывает 12 форм: акт ИТД (АОСР, АООК, акт ИТО), запись в журнал, заявка на закупку, смета, счёт, акт / КС-2 и КС-3, договор, объект, задача, заявка заказчика, раздел ПД, исполнитель. Номера документов ставятся по порядку автоматически.
- **Глобальный поиск** (Ctrl K): объекты, акты, журналы, сертификаты, сметы, закупки, счета, банк, исполнители, ИНН. По результатам можно ходить стрелками, Enter открывает выбранный.
- **Карточка объекта**: в каждой зоне видны свои вкладки, например в ИТД это комплекты ИТД, журналы и сертификаты.
- **Тема**: светлая, тёмная или как в системе (кнопка с монитором в шапке).

## Где хранятся данные

| Режим | Примерные данные | Созданные записи |
|---|---|---|
| claude.ai (артефакт) | в `index.html` | общая база артефакта, видна всем, у кого есть доступ |
| Файл или свой сервер | в `index.html` | `localStorage` этого браузера |

Чтобы очистить созданные записи в автономном режиме, удалите данные сайта в настройках браузера.

Примерные данные лежат в начале скрипта в `index.html`, в массивах `OBJ`, `EST`, `IDACTS`, `JOURNALS`, `CERTS`, `PUR`, `CONTRACTS`, `INVOICES` и других. Их можно заменить реальными.
