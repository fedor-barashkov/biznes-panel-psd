# Бизнес-панель ПСД

Панель управления проектно-сметным бюро в трёх рабочих зонах:

- **Сметы**: сметы, проектная документация, замечания экспертизы.
- **ИТД**: исполнительная документация по Приказу Минстроя 344/пр, журналы работ (1026/пр), сертификаты и паспорта.
- **Бизнес**: договоры, счета, акты, банк, закупки, заказчики, исполнители, интеграции.

Объекты, задачи, глобальный поиск и AI-помощник общие для всех зон.

> Панель открывается пустой. Начните с объекта, остальные документы привязываются к нему.

## Состав репозитория

| Файл | Что это |

| `index.html` | Вся панель в одном файле: вёрстка, стили, данные и логика |

## Три способа запуска

### 1. На claude.ai: полная версия (рекомендуется)

Панель опубликована как артефакт Claude, ссылка «Бизнес-панель ПСД» есть в разделе артефактов claude.ai. Только в этом режиме работает всё:

- **AI-помощник** отвечает по данным панели и пишет письма;
- **AI-поиск поставщиков** даёт ориентировочные цены и сроки;
- **общая база записей**: созданные акты, заявки, счета и объекты видны всем, с кем вы поделились панелью.

Чтобы дать доступ сотрудникам, откройте артефакт и нажмите «Поделиться».

Если панель нужно опубликовать заново, например после правок в `index.html`, попросите Claude: «опубликуй index.html из репозитория как артефакт с возможностями db, sample и downloads».

### 2. На своём компьютере: без установки

1. Скачайте репозиторий: на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте `index.html` двойным щелчком. Подойдёт Chrome, Edge, Safari или Firefox.

Работает всё, кроме AI. Данные хранятся только в этом браузере на этом компьютере: в шапке будет надпись «В этом браузере». Регулярно скачивайте резервную копию (см. ниже). Для значков нужен интернет, они загружаются с unpkg.com.

### 3. На внутреннем сервере или хостинге

Положите `index.html` в любую папку веб-сервера (nginx, Apache, IIS) или на статический хостинг. Настраивать ничего не нужно. Возможности будут как в способе 2.

Быстрая проверка через Python:

```bash
cd biznes-panel-psd
python3 -m http.server 8080
# откройте http://localhost:8080
```

> GitHub Pages для закрытого репозитория доступен только на платных тарифах GitHub (Pro, Team, Enterprise).

## Что умеет панель

- **Переключатель зон** в шапке: «Сметы / ИТД / Бизнес». Панель запоминает последнюю открытую зону.
- **Кнопка «Создать»** открывает формы: объект, задача, смета, раздел ПД, комплект ИТД, акт ИД, журнал, запись в журнал, документ о качестве, заявка на закупку, договор, счёт, акт / КС-2 и КС-3, расчётный счёт, операция по счёту, заявка заказчика, исполнитель. Номера документов ставятся по порядку автоматически.
- **Редактирование и удаление:** нажмите на строку любой таблицы или на значок карандаша. В форме есть кнопка «Удалить» с подтверждением.
- **Комплекты ИТД:** в карточке объекта, вкладка «ИТД» → «Вид работ». Панель подставляет нормативный перечень документов, вы указываете, сколько нужно и сколько готово.
- **Задачи** отмечаются выполненными галочкой. Счёт можно отметить оплаченным кнопкой в таблице. Просрочки подсвечиваются автоматически.
- **Деньги:** заведите расчётный счёт с остатком и вносите операции. Остатки, графики и «к оплате» считаются сами.
- **Глобальный поиск** (Ctrl K): объекты, акты, журналы, сертификаты, сметы, закупки, счета, банк, исполнители, ИНН. По результатам можно ходить стрелками, Enter открывает выбранный.
- **Карточка объекта**: в каждой зоне видны свои вкладки, например в ИТД это комплекты ИТД, журналы и сертификаты.
- **Тема**: светлая, тёмная или как в системе (кнопка с монитором в шапке).

| Режим | Где хранятся данные |

## Инструкция внутри панели

В каждой зоне есть пункт меню **«Инструкция»**, а в шапке — кнопка со знаком вопроса. Там пошагово: первый запуск, как заполнять формы, частые задачи (АОСР, журнал, комплект ИТД, смета, счёт, банк, закупки), печать и ответы на частые вопросы. Кнопки в инструкции сразу открывают нужную форму.

## Печать документов

Печатаются: **АОСР и другие акты ИД** (по форме Приказа Минстроя 344/пр, прил. 3), **счёт на оплату** (с банковскими реквизитами и суммой прописью), **акт сдачи-приёмки и КС-2/КС-3**, **журнал работ** со всеми записями и **реестр ИД** по объекту.

1. Нажмите значок принтера в строке документа или кнопку «Печать» в его форме. Реестр ИД — кнопка «Реестр ИД» в объекте, вкладка «ИТД».
2. Проверьте предпросмотр.
3. Печать:
   - **файл на компьютере:** «Распечатать» сразу открывает окно печати;
   - **claude.ai:** «Скачать для печати» → откройте файл двойным щелчком → кнопка «Печать» вверху документа или Ctrl+P. Файл также открывается в Word.

Чтобы в АОСР подставлялись участники и представители, заполните их один раз в карточке объекта («Изменить» → блок «Участники»). Для счетов заполните банковские реквизиты в «Доступ и настройки» → «Реквизиты».

В режиме файла любую страницу панели можно распечатать через Ctrl+P: меню и кнопки при печати скрываются.

## Резервная копия и перенос данных

«Доступ и настройки» → «Данные»:

- **Скачать резервную копию:** файл `biznes-panel-ГГГГ-ММ-ДД.json` со всеми записями.
- **Загрузить из копии:** добавляет записи из файла. Так можно перенести данные с компьютера на claude.ai и обратно или на другой компьютер.
- **Удалить все данные:** очищает панель, требует подтверждения.

Если вы работаете с файлом на компьютере, делайте копию хотя бы раз в неделю: при очистке данных браузера записи пропадут.

## Новый самостоятельный контур ИТД (в разработке)

В ветке `itd-product-bootstrap` начат отдельный desktop-каркас приложения ИТД:

- локальная SQLite;

- файловое хранилище оригиналов с SHA-256;

Этот контур не заменяет исходный HTML и не изменяет его; он является началом самостоятельного продукта. Подробности и текущие ограничения — в `docs/DEV_STATUS.md`.
