# Реестр архитектурных решений и открытых вопросов

**Версия:** 0.1  
**Дата:** 2026-11-08  
**Назначение:** единый журнал решений для проектирования экосистемы ИТД и строительных ИИ-агентов.

## 1. Правила статусов

- **Утверждено** — пользователь прямо подтвердил решение.
- **Ранее утверждено** — решение было подтверждено в предыдущих обсуждениях и перенесено в текущую консолидацию.
- **Предложение** — рабочая рекомендация, требующая подтверждения.
- **Требует проверки** — необходим исходный файл, нормативный источник, технический аудит или испытание.
- **Открыто** — решение ещё не принято.

Если обнаружено противоречие, приоритет имеет более позднее прямое решение пользователя. Не менять утверждённые решения молча.

## 8. Правила работы с открытыми вопросами

- Не задавать пользователю весь список вопросов одновременно.
- Сначала самостоятельно исследовать доступные репозитории, файлы и нормативные источники.
- Задавать один наиболее важный вопрос только тогда, когда без решения нельзя продолжать.
- Не просить повторно файл, пока не проверены доступные вложения и библиотека.
- Не считать отсутствие найденного файла доказательством, что он потерян.
- Не превращать предложенный вариант в утверждённое решение.
- При изменении решения указывать, какой пункт и почему заменён.
