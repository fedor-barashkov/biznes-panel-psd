# Статус разработки

**Дата:** 2026-11-10  
**Ветка:** itd-product-bootstrap

## Реализовано в начальном каркасе
- .NET 10 solution с разделением Core / Infrastructure / Desktop.
- WPF desktop shell.
- Локальная SQLite база с первичной схемой, внешними ключами и WAL.
- CRUD-сценарий создания и чтения карточек объектов.
- Запись события создания объекта в audit_events в той же транзакции.
- Модели и репозитории организаций и подобъектов.
- Файловое хранилище с SHA-256 и дедупликацией оригиналов.
- Windows GitHub Actions build/test/publish pipeline.
- Первичные инфраструктурные тесты SQLite; первая Windows CI-проверка выявила проблему удержания файлов SQLite connection pool, устранённую отключением pooling для предсказуемого закрытия/резервирования.

## Не подтверждено
- Успешная сборка и тесты на Windows (workflow пока не запущен/не подтверждён).
- Поведение на целевой Windows машине.
- Визуальное соответствие печатных форм.
- Восстановление резервной копии.
- Полный импорт DOCX/XLSX/PDF/OCR.
- Полноценная авторизация и права.
