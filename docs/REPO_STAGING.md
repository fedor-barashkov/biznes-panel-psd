# Временное размещение исходников приложения ИТД

**Дата:** 2026-11-10  
**Статус:** временная техническая площадка; не целевой репозиторий продукта.

## Почему исходники находятся здесь

Целевая архитектура предусматривает самостоятельный репозиторий приложения ИТД. Доступный в текущей рабочей среде GitHub-инструментарий позволяет читать и изменять файлы, создавать ветки и pull request, но не предоставляет операцию создания нового репозитория.

Чтобы не останавливать разработку и не менять main существующих проектов, исходный каркас размещён в отдельной ветке `itd-product-bootstrap` текущего репозитория. Это staging branch для подготовки исходников, CI и первого рабочего вертикального сценария.

## Правила безопасности и переноса

- `main` не изменялась.
- Исходники `manager-executive-schemes`, `itd.html` и `pult-otdela` не изменялись.
- Новый код ИТД изолирован в `src/ITD.*`, `tests/ITD.Infrastructure.Tests` и `ITD.sln`.
- Документация проекта находится в `docs/ITD` и не смешивается с кодом продукта.
- После создания целевого репозитория перенести содержимое продуктовой части без переноса старой бизнес-панели и без слияния в её main.
- До переноса staging branch не считать окончательным размещением продукта.
