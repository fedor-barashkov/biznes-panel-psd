# Документация самостоятельного приложения ИТД

Проектная документация приложения для подготовки, ведения, проверки, комплектования и передачи исполнительной документации на объектах капитального строительства.

## Состав
- [Техническое задание](Техническое_задание.md) — функциональные и нефункциональные требования.
- [Архитектура](Архитектура.md) — целевая архитектура, доменные модули и потоки данных.
- [Макеты](Макеты.md) — решения и статусы согласования.
- [Регламенты](Регламенты.md) — правила разработки, обработки документов и контроля качества.
- [История изменений](История_изменений.md) — хронология решений.

## Статус
Это проектная документация, а не подтверждение реализованной функциональности. Утверждённые решения отделяются от предложений и открытых вопросов. Макет 1.0.15 спроектирован, но целиком ожидает отдельного окончательного утверждения. Реализация не начинается до завершения аудита исходных материалов, согласования ТЗ/макетов и архитектурного проектирования.
