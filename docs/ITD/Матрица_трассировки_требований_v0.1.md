# Матрица трассировки требований ИТД

**Версия:** 0.1  
**Основание:** ТЗ приложения ИТД v0.6 и план приёмочных испытаний v0.1.  
**Статус:** подготовлена; связь с фактическим кодом появится после реализации.

|---|---|---|
| 1–2 | Назначение, объекты, подобъекты | ITD-001–003 |
| 3 | Карточка объекта, организации, СРО, представители | ITD-004–005 |
| 4 | Импорт, OCR, аналогичный объект | ITD-006–009 |
| 5 | АОСР и акты ИД | ITD-010–012 |
| 6 | Материалы, партии, документы качества | ITD-017 |
| 7 | Исполнительные схемы | ITD-016 |
| 8 | Протоколы | ITD-018 |
| 9 | ПД/РД и редакции | ITD-004, ITD-022 |
| 10 | ОЖР и специальные журналы | ITD-019 |
| 11 | ВОР и объёмы | AG-002–003; вспомогательный контур |
| 12 | Комплектность ИД | ITD-020–023 |
| 13 | Реестр, комплект, передача, приёмка | ITD-020, ITD-023–025 |
| 14 | Рабочая панель ПТО | ITD-031–032 |

| 22 | ИИ, хранилища и интеграции | AG-001–006, ITD-030 |
| 23–25 | Нефункциональные требования, preview, шаблоны, выпуск | ITD-001, ITD-013–015, ITD-032–034 |
| 26 | Уточнения интерфейса и передачи | ITD-010, ITD-015, ITD-020, ITD-023–025 |

**Правило:** требование считается реализованным только при наличии ссылки на конкретный commit/компонент и пройденный тест. Наличие текста в ТЗ или макете не является доказательством реализации.
