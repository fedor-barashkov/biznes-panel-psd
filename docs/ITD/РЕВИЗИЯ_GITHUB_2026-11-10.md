**Платформа агентов:**

- QA/Reviewer описан как компонент платформы, но отдельный файл роли QA в `docs/AGENTS/roles` не обнаружен;

- это пока спецификация, не исполняемая агентная система.

**Приложение ИТД:** согласно `docs/DEV_STATUS.md`, не подтверждены запуск EXE на ПК пользователя, installer/MSIX, точность печатных форм, восстановление резервной копии, полный импорт DOCX/XLSX/PDF/OCR и полноценная авторизация/права.

**Локальные файлы:** пользовательский архив Автогенератора и шаблоны не становятся частью GitHub автоматически. Их нельзя загружать в публичный репозиторий без отдельного решения о приватности и лицензировании.

Предыдущий стартовый ZIP был локальным артефактом, а не файлом репозитория. Попытка создать расширенную версию ZIP в текущей сессии не завершилась; считать её созданной нельзя.

Это также снижает риск случайно смешать продуктовый код с документационным staging-репозиторием.
